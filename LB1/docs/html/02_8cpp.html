Detailed Description

Обработка одномерного динамического массива.

Демонстрирует:

  • работу с new/delete для одномерного динамического массива;
  • передачу указателя по ссылке (int*&), чтобы изменить сам указатель;
  • усечение массива до первого отрицательного элемента без утечек памяти;
  • защиту от «болтающихся указателей» (dangling pointers) после delete.

int main ( )

Точка входа. Демонстрирует обработку динамического массива.

Сценарий:

  1. Пользователь вводит размер N и N элементов.
  2. Массив выводится на экран.
  3. Вызывается process() — массив усекается до первого отрицательного.
  4. Выводится результат (или сообщение о пустом массиве).
  5. Память освобождается, указатель обнуляется.
  6. Демонстрируется безопасное поведение: проверка на nullptr перед разыменованием предотвращает Segmentation Fault.
Returns
0 — успешное завершение или некорректный размер.

◆ process()

void process ( int *& arr,
int & size )

Обрабатывает массив: усекает его до первого отрицательного элемента.

Алгоритм:

  1. Ищет первый отрицательный элемент.
  2. Если такого нет — массив не изменяется, выводится сообщение.
  3. Если найден — создаётся новый массив размером negIndex, в него копируются все элементы до отрицательного, старая память освобождается, а указатель arr перенаправляется на новый массив.

Указатель передаётся по ссылке (int*&), чтобы изменить сам указатель в вызывающем коде. Размер size также передаётся по ссылке, так как он меняется после усечения.

Parameters
arrСсылка на указатель на массив. После вызова может указывать на новый массив (если найден отрицательный элемент).
sizeСсылка на размер массива. Обновляется до нового размера.
Note
Если отрицательный элемент первый (negIndex == 0), создаётся массив нулевого размера, а size становится равным 0.
Warning
Перед вызовом arr должен указывать на память, выделенную через new[] (не nullptr и не статический массив).
