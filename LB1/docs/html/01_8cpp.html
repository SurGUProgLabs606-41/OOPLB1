Detailed Description

Операции над статическим массивом целых чисел.

Демонстрирует работу с массивом фиксированного размера через ссылки:

  • заполнение случайными числами;
  • вывод элементов;
  • обмен двух элементов по индексам;
  • умножение всех элементов на 2.

Использование ссылок на массив int (&arr)[10] позволяет сохранять информацию о размере и избегать затухания массива до указателя.
