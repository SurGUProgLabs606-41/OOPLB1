Detailed Description

Реализация «безопасного массива» SafeArray с контролем границ.

Демонстрирует:

  • структуру SafeArray, инкапсулирующую указатель и размер;
  • безопасный доступ к элементам через getElement() с защитой от выхода за границы;
  • использование функции доступа слева от знака равенства (возврат ссылки);
  • печать массива без его изменения (const-ссылка);
  • изменение размера массива с сохранением данных и выводом удалённых элементов.

◆ getElement()

int & getElement ( SafeArray & arr,
int index )

Безопасный доступ к элементу массива по индексу.

Если индекс выходит за границы [0; arr.size), выводит сообщение об ошибке в std::cerr и возвращает ссылку на статическую переменную-заглушку. Это позволяет использовать функцию слева от знака равенства даже при некорректном индексе — без падения программы и без порчи основного массива.

◆ reSizeArray()

void reSizeArray ( SafeArray & arr,
int N,
int M )

Изменяет размер SafeArray с N элементов на M.

Поведение:

  • Если M < N: элементы с индексами [M; N) выводятся на экран как «удалённые», затем отбрасываются.
  • Если M > N: новые элементы инициализируются нулями.
  • Данные, попадающие в новый диапазон, копируются.

Старая память корректно освобождается, указатель перенаправляется на новый массив.

Parameters
arrСсылка на SafeArray, размер которого нужно изменить.
NТекущий (старый) размер массива. Должен совпадать с arr.size.
MНовый размер массива (может быть 0).
Note
Параметр N дублирует arr.size и присутствует для соответствия формулировке задания. Если N != arr.size, выводится предупреждение, а за основу берётся arr.size.
